# 原方案与当前范围

用户已确认 DSH 版、magirisyang 账号、私有仓库 andrej-karpathy-dsh-plugin。本机宿主为 0.2.0-rc.2。

“查找理解模型输出技巧”分享会话已完整读取，包含三个阶段、七项困难和八项验收建议。原方案建议 DSH + OpenDesign + 中文 Skill；本次指定 DSH 版，因此采用原生工具和全局提示，复用文件、shell/job、交付与权限机制，OpenDesign 作为可选后续集成。

| 要求 | 已实现 | 边界 |
| --- | --- | --- |
| 按任务升级格式 | 规则路由、auto、用户覆盖 | 模型是否调用受会话指令影响 |
| 中文规范与检查 | 写作提示、术语表、机械 Linter | 不是语义事实核验器 |
| 图解 | 固定 SVG、独立关系图例、空间网格图 | 不是通用图形编辑器 |
| 真实参数交互 | 空间分折和最近邻预测 | 模拟数据，不是真实 RF；仅一种内置模拟 |
| 统一事实 | knowledge.json，来源与假设分开 | 上游模型组织，程序校验引用和结构 |
| 中文视频 | 离线慧慧语音、MP4、烧录字幕/SRT | 幻灯片及淡入，尚无复杂机制动画 |
| 多轮编辑 | 内容哈希、旧阶段复用、新版本保留 | 不是原文件富文本编辑 |
| 分段渲染 | 场景缓存、进度、续跑 | 经现有 shell/job，依赖须可用 |

已验证实际 DSH 模块、计算、浏览器交互和 Windows 有声视频。未修改正在运行的用户 profile，也未测量大量普通问题的模型触发成功率。

GitHub 插件已安装且用户确认连接 magirisyang；当前回合尚无仓库工具。创建和上传仅以实际远端核验为准，不能把本地 origin 当作已上传。
