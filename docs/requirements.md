# 需求与范围

## 已确认

- 目标宿主：DeepSeek Harness（DSH），本机桌面版运行时 0.2.0-rc.2。
- 工作目录：`D:\插件开发\Andrej-Karpathy插件`。
- GitHub：`magirisyang/andrej-karpathy-dsh-plugin`，私有仓库。
- 参考会话：“查找理解模型输出技巧”。已读取到用户讨论 Karpathy 四种输出方法、Open Design 能否实现，以及具体实施难点的提问。

## 信息缺口与实现假设

会话接口的助手正文只返回内容引用，浏览器未能读取完整方案。因此当前实现不是对原会话助手方案的逐项复刻。已向用户请求正文；在等待期间先实现四种输出的 DSH 原生插件。

四种方式落地为：简明中文、SVG 图解、交互 HTML、可播放的字幕时间轴与浏览器 WebM 导出。未接入 Open Design 的服务，也未引入 TTS 或远程视频 API。完整有声视频、自动 MP4、复杂动画与自定义 DSH 客户端工具卡片是后续扩展点。

## 验收

1. 作为 DSH bundle 安装，不修改宿主源码。
2. 注册一个模型可见工具，输出格式一致且可单独打开。
3. 保留结构化说明中的来源、不确定性和所有要点；模型生成内容的事实正确性仍取决于上游资料与判断。
4. 不执行输入内容中的 HTML/代码，不自动上传数据，不额外调用模型。
5. 文件操作通过 DSH 文件服务，带会话工作目录与原有沙箱策略，使用原子 createIfAbsent。
6. Git 有可追踪提交与版本标签，私有 GitHub 仓库上传后核验远端提交。
