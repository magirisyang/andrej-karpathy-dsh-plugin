### 0.2.1 安装格式修正

- 主要入口改为 DSH 插件页面输入 `github:magirisyang/andrej-karpathy-dsh-plugin`；私有仓库需要安装电脑的 Git 授权。保留 desktop/web 命令行安装和开发目录安装。
- 修正组合包声明为 `dsh.bundle.patch` 对象，配置层用 `insert` 新增插件行。旧声明无法被本机标准组合包加载器正确注册。
- 已打包 0.2.1，在项目内的独立临时 profile 模拟安装包，使用本机发行版真实 `loadProfileDirectory` 和 `composeEntries` 验证：1 个组合包层、1 条 karpathy-explain 插件行，默认配置正确；无跳过组合包和配置警告。未修改用户运行中的 profile。
- 此检查验证安装包识别与配置组合；尚未通过运行中的桌面插件页面执行端到端安装。

### 0.2.0 功能验证

- 13 项针对性 Node 检查通过：实际工具 Schema、目录/创建模式、沙箱传递、取消与边界、默认文字、重复零写入、跨版本 SVG 复用、内容保留、注入处理、节点引用、路由、独立计算、机械 Linter、真实 Cordis 与文件服务挂载/卸载。
- 后续修改页面和 SVG 后，只重跑相关渲染检查，全部通过。
- 空间模拟与独立最近邻计算一致，同网格不同时进入训练和验证；网格变化时坐标和类别不变。
- 浏览器网格 10：训练 93、验证 27、模拟准确率 81.5%、平均最近距离 9.43；网格 30：训练 108、验证 12、91.7%、10.12。均为模拟最近邻结果。
- 浏览器搜索、展开/收起、WebM 导出通过。
- Windows MP4：慧慧中文旁白、1280×720 H.264、AAC、烧录中文字幕及 SRT；已验证可解码、非静音音轨，提帧检查中文显示。
- 修正字幕边界后的两场景 MP4 约 20.5 秒。只改第二场景的版本约 23.35 秒，第一场景复用，reusedScenes=[0]，原视频保留。

临时使用已安装官方 DSH 模块，放在忽略的 node_modules，不随插件上传。视频验证使用已有 Pillow 12.3.0，以及项目临时目录内的 imageio-ffmpeg 0.6.0、comtypes 1.4.13。

PowerShell 曾阻止语音脚本，最终改为 Python 直接调用 SAPI，没有改变执行策略，没有使用云语音服务。
